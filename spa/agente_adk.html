Sesión 08

Un agente que piensa, actúa y observa

Un modelo de lenguaje pequeño (qwen3:4b, servido por Ollama en el servidor del laboratorio) envuelto en un LlmAgent de Google ADK con tres herramientas de Python. Todo lo que ves aquí sale de una ejecución real del agente asistente_teresa.

01

El bucle ReAct

El agente elige una acción \(a_t\) según una política inducida por el modelo, \(\pi_\theta(a \mid h_t) = p_\theta\big(c(a) \mid h_t\big)\), sobre un historial \(h_t\) que crece en cada vuelta. Cada vuelta tiene cuatro pasos; en el reproductor de la sección 2 se ilumina el que está ocurriendo.

Pensar

\[ r_t \sim p_\theta(\cdot \mid h_t) \]

El modelo genera tokens de razonamiento. En qwen3 llegan como partes con thought=True.

Actuar

\[ a_t \sim p_\theta(\cdot \mid h_t, r_t) \]

Elige llamar a una herramienta \(f_k\) con argumentos \(\mathbf{u}_t\), o responder.

Observar

\[ o_t = f_k(\mathbf{u}_t) \]

Python ejecuta la función que el modelo pidió y devuelve el resultado.

Actualizar

\[ h_{t+1} = h_t \oplus (r_t, a_t, o_t) \]

La observación entra al historial y el modelo se consulta otra vez.

El bucle se detiene en \(\tau = \min\{t : a_t = \textsf{responder}(y)\}\). Si cada vuelta sale bien con probabilidad \(q\), una tarea de \(K\) vueltas sale bien con probabilidad \(\approx q^{K}\): pocas vueltas y herramientas claras ayudan mucho a un modelo pequeño.
